Select a Sticky Scroll & Animation Upgrade

Pick the animation pattern that will make the features section feel premium, fluid, and premium.

A

Approach 1: Progressive Element Reveal (Recommended)

How it works: A single, high-fidelity dashboard mock container is always visible. As you scroll, elements *inside* the dashboard animate in sync with the active text block:

  • Step 1 (Evaluation): The mock answer sheet appears, and AI point redlines draw themselves sequentially.
  • Step 2 (Mock Papers): The answer sheet morphs into a mock exam paper, scrolling through structured questions.
  • Step 3 (Dashboard): The paper fades, and subject proficiency bar charts grow from 0% to their values.

Uses framer-motion's layoutId and smooth transitions to morph the visual content in place, preventing abrupt flips.

  • Highly fluid, feels like a single cohesive interface morphing
  • Zero jarring transitions or abrupt layout jumps
  • Requires careful coordination of UI states
B

Approach 2: Cross-Fade Stack with Scale-In

How it works: The 3 mockups (Evaluation, Paper, Charts) are pre-loaded in an absolute-positioned stack. When you scroll to a feature, the active mockup fades in (opacity: 1, scale: 1) and the inactive ones fade out (opacity: 0, scale: 0.95) in place.

We also increase the scroll section height to 80vh to give the user plenty of scroll space before a mockup changes, preventing rapid flurries of swaps.

  • Clean and straightforward to interact with
  • More breathing room while scrolling
  • Does not morph elements, still switches distinct panels
C

Approach 3: Horizontal Timeline Track

How it works: As you scroll vertically, the section locks in place (pinning) and horizontal scrolls through 3 full-width columns showing the features side-by-side with large-scale visuals.

  • Extremely high visual impact, cinematic
  • Can feel heavy and break the page's vertical reading flow
